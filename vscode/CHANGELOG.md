# Changelog

## 1.5.1

First public release.

- Dark (Ajisai Rainbow) and light (Ajisai Rainbow Light) variants.
- Syntax colors assigned by how often each color appears in the original picture: deep green keywords, vivid green strings, hydrangea-blue functions, sea-colored types, and purple only as an accent for numbers and constants.
- Bracket pair colors from the rainbow (lavender, mint, sky blue).
- Light variant uses a pale mint editor background and more saturated text colors so tokens stay distinguishable.
- Colors for the chat input and request bubbles.
